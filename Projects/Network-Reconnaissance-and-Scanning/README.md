# 🔎 Network Reconnaissance and Scanning

## 📌 Project Overview

This project focused on footprinting, reconnaissance, and network scanning techniques used during the information-gathering phase of a cybersecurity assessment.

The lab provided hands-on experience with identifying systems, gathering information about a target environment, and using reconnaissance and scanning techniques to better understand potential attack surfaces and security risks.

## 🎯 Objectives

- Understand the purpose of footprinting and reconnaissance
- Gather information about target systems and networks
- Perform network scanning and enumeration
- Identify active hosts, services, and potential points of exposure
- Analyze information collected during reconnaissance
- Document findings from the investigation
- Develop practical skills used in vulnerability assessment and security analysis

## 🛠️ Skills Demonstrated

- Network Reconnaissance
- Footprinting
- Network Scanning
- Host Discovery
- Service Enumeration
- Information Gathering
- Vulnerability Identification
- Network Security
- Security Analysis
- Technical Documentation

## 🔍 Project Summary

During this lab, I worked through the reconnaissance and scanning process to gather information about a target environment.

The project involved identifying systems and network information, examining available services, and analyzing the results to better understand how cybersecurity professionals map an environment before performing deeper security assessments.

This exercise strengthened my understanding of how reconnaissance can be used to identify potential vulnerabilities and provided hands-on experience with techniques commonly used by security analysts and penetration testers.

## 🔐 Security Takeaways

Reconnaissance is an important part of cybersecurity because understanding what information and services are exposed can help organizations identify weaknesses before they are exploited by an attacker.

This project demonstrated how information gathered through footprinting and network scanning can support vulnerability assessments, threat analysis, and defensive security operations.
